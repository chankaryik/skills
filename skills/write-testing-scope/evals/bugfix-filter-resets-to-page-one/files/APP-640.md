# APP-640 Reports > Activity log & Settings > Audit log: table goes empty when the date range changes on page 2 or later

**Problem Statement:**

In **Reports > Activity log** and **Settings > Audit log**, when a user goes to any page after page 1 and then changes the date range (e.g. from **Last 7 days** to **Last 30 days**), the table shows "No activity found", even though the API returns the right data. Both logs are affected. Reproducible on production.

**Steps to reproduce**

1. Log in on staging or production.
2. Go to **Reports > Activity log**.
3. Go to page 2 or later.
4. Change the date range (e.g. **Last 30 days**, or a custom range).
5. The table shows "No activity found", but the Network tab shows the API returned rows.
6. Go to **Settings > Audit log**.
7. Go to page 2 or later.
8. Change the date range.
9. The table is empty here too.

**Reproducible on production:** Yes

**Expected behaviour:**

When the date range changes from any page, the table should go back to page 1 and show the matching rows right away, the same as when you change it from page 1.
